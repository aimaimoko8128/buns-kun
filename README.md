## 現在の開発状況 (Claude による自律開発)

地上から地下へ5層潜っていく、シード制の2D洞窟ローグライク。
コアループ（探索 → 具材収集 → ビルド構築 → 戦闘 → 部屋クリア → 強化 → 次の層 → ボス）が一通りプレイ可能です。

**シーンやPrefabの手動設定は不要です。** `Assets/Scenes/SampleScene.unity` を開いて Play するだけで、
`GameBootstrap`（`Assets/Scripts/Game/GameBootstrap.cs`）が起動時にカメラ・UI・プレイヤー・ダンジョンを
すべてコードから生成し、最初のランが始まります。

### 操作方法

| 操作 | アクション |
| --- | --- |
| A / D、← / → | 移動 |
| Space（単押し） | ジャンプ |
| Space（長押し） | ジェットパックで上昇（燃料ゲージを消費、着地で回復） |
| 左クリック | 次の具材を発動 |
| Tab | インベントリ（具材のセット・並べ替え・バンズ変更） |
| F1 | シード表示 / 任意のシードでランを開始 |

### マップ生成について

同じシードなら必ず同じダンジョンになります。生成は段階に分かれています。

```text
Seed → 部屋グラフ → 洞窟生成 → 足場生成 → 到達可能性検証(＋修復) → 敵/アイテム配置 → 最終Validation
```

* 洞窟はセルオートマトン＋チャンバー＋起伏地形で掘り、単純な矩形の部屋にはしていません
* 到達可能性は**プレイヤーの実際の性能**（ジャンプ力・重力・移動速度・Collider・ジェットパック）から計算します
  （`PlayerMovementProfile` が `PlayerController` の値を読みます）
* 「必ず通れるルート」（各ドア・層の出口・ボス）はジャンプだけで到達できることを保証し、
  ジェットパックは寄り道や高所用の位置付けです
* 到達できない場所があった場合、シードを引き直さずに**決定的な修復**（通路の掘り直し）を行うため、
  同じシード → 同じ最終マップが常に成立します

生成コードは Unity 外でもコンパイル・実行して検証しており、1500層（300ラン分）でValidation失敗0件、
1層あたり約5msで生成されます。

### 実装済みの内容

* プレイヤー：移動・ジャンプ・ジェットパック・被ダメージ・死亡
* 具材システム：攻撃系6種 + 強化系5種、順番依存の効果、マナ、発動ディレイ
  （ラン開始時は基本具材「Breadcrumb」を1つ装備した状態から始まります）
* バンズ5種：スロット数 / マナ / 移動速度 / 被ダメージが変化。探索中に入手し Tab で装備変更
* 敵5種（近接・高速・遠距離・重量・飛行）+ ボス1体
* シード制のプロシージャル洞窟生成、施錠ドア、寄り道部屋、環境ハザード
* 部屋クリア時のラン限定強化（10種、シードから事前決定）
* 5層構成、深くなるほど敵が強化される
* Game Over / Victory 画面と新しいランの開始

見た目は仮素材（コードで生成した図形）です。まずゲームシステムの完成を優先しています。

### アーキテクチャ

```text
Assets/Scripts/
├── ProceduralGeneration/   TileMap / TerrainCarver / ReachabilityAnalyzer /
│                           LayerGenerator / TerrainRenderer / RoomBuilder ...
├── Player/ Combat/ Ingredients/ Buns/ Enemies/ Rooms/ Upgrades/ Pickups/ UI/ Game/
```

ScriptableObject 系のデータ（具材・バンズ・敵・強化）は `.asset` ファイルではなく各 `*Database.cs` の中で
コードから生成しています。エディタでの手動アセット管理が不要で、参照切れが起きない構成です。
