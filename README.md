## 現在の開発状況 (Claude による自律開発)

コアゲームループ（移動→ジャンプ→戦闘→具材収集→具材セット→左クリックで発動→マナ消費→部屋クリア→強化→次の部屋→ボス撃破）が
一通りプレイ可能な状態です。

**シーンやPrefabの手動設定は不要です。** `Assets/Scenes/SampleScene.unity` を開いて Play するだけで、
`GameBootstrap`（`Assets/Scripts/Game/GameBootstrap.cs`）が起動時にカメラ・UI・プレイヤー・ダンジョンをすべて
コードから生成し、最初のランが自動的に始まります。

### 操作方法

* A / D または ← / →: 移動
* Space: ジャンプ
* 左クリック: 次の具材を発動
* Tab: インベントリ（具材セット・バンズ切り替え）を開閉

### 実装済みの内容

* プレイヤー移動・ジャンプ・被ダメージ・死亡
* 具材システム（攻撃系5種 + 強化系5種、順番依存の効果、マナ、発動ディレイ）
* バンズシステム（5種、スロット数/マナ/移動速度/被ダメージが変化、探索中に入手して装備変更可能）
* 敵5種（近接・高速・遠距離・重量・飛行）+ ボス1体（複数攻撃パターン）
* プロシージャルなダンジョン生成（部屋グラフ、メインルート+寄り道の任意部屋、施錠ドア、地形・足場）
* 部屋クリア時のラン限定強化（10種）、部屋クリアでロック解除
* 3エリア構成、エリアが進むごとに敵が強化される
* Game Over / Victory 画面と新しいランの開始

見た目は仮素材（コードで生成した単色図形）です。まずゲームシステムの完成を優先しています。

### アーキテクチャ

`Assets/Scripts/` 以下に `CLAUDE.md` のアーキテクチャ方針に沿って機能ごとにフォルダ分けしてあります。
ScriptableObject 系のデータ（具材・バンズ・敵・強化）は `.asset` ファイルではなく、各 `*Database.cs` の中で
コードから `ScriptableObject.CreateInstance` して構築しています。エディタでの手動アセット管理が不要になり、
参照切れが起きない構成です。
